# Figures Directory Guide (Manuscript & Supplementary Material)

This directory contains all diagnostic plots, ROC curves, confusion matrices, convergence trajectories, capacity-matched ablation bar charts, and participant-level paired statistical figures generated for the **TimePatch-SSL** manuscript and Supplementary Material.

Full publication-ready captions (in English and Spanish) for every figure are provided in [`docs/supplementary_material_figures_and_tables_guide.md`](../../docs/supplementary_material_figures_and_tables_guide.md).
